# Hassh Wears - Master Prompt & Guidelines

This document serves as the master guideline for the design, development, SEO, AEO, GEO, and CRO optimization of the Hassh Wears B2B apparel manufacturing website.

---

## BRAND & THEME
- **Brand Name**: Hassh Wears
- **Business Type**: Premium B2B Apparel Manufacturer
- **Theme Colors (LOCKED)**: 
  - ONLY Black, White, Grey Shades, Red Shades (Dark Red, Deep Red, Ultra Dark Red, Bright Red).
  - NO Purple, Lavender, Blue, Cyan, Green, Yellow, Orange, Gold.
  - All glows, shadows, gradients, borders, hover effects, icon highlights, animations, and lighting effects must use black and red shades.
- **Design Style**: Luxury, Minimal, Corporate, Modern, Premium, Apple Inspired, Vercel Inspired, Stripe Inspired, Awwwards Quality, Dark UI, Glassmorphism, Soft Shadows, Luxury Animations, Large White Space, Professional Typography.

## CORE REQUIREMENTS

### 1. SEO (Search Engine Optimization)
- Semantic HTML5 structure.
- Single H1 per page, keyword-rich hierarchy (H2-H6).
- Schema.org structured data (Organization, Local Business, Product, FAQ, Breadcrumb).
- Optimized Meta Titles, Descriptions, Canonical URLs, and Open Graph / Twitter Cards tags.
- Image ALT texts.
- Performance & Core Web Vitals optimization (Lazy loading, lightweight CSS/JS).

### 2. AEO (Answer Engine Optimization)
- Question-based headings, FAQ sections, short answer boxes.
- Direct, clear, and conversational content structure suitable for AI models (Gemini, ChatGPT, Claude, Perplexity, Voice Search).

### 3. GEO (Generative Engine Optimization)
- Entity-rich content (clear definition of terms, manufacturer terminology, fabric glossary).
- Strong topical authority and EEAT signals (certifications, production process details, fabric library details).
- Contextual internal linking & clear product/service relationships.

### 4. CRO (Conversion Rate Optimization)
- Sticky Call-To-Action (CTA), WhatsApp button, Factory Tour request, MOQ Calculator, instant RFQ Form, Catalog download.
- Trust badges, certifications, testimonials, case studies.

---

## MAIN WEBSITE SECTIONS
- **Hero**: Luxury introduction with premium typography and visual impact.
- **About Us**: Enterprise profile, factory size, capacity, global reach.
- **Products**: Interactive showcase of Streetwear, Fashion Wear, Casual Wear, Sportswear, Workwear.
- **Manufacturing Services**: Cutting, sewing, custom prints, embroidery, labeling, private label services.
- **Production Process**: Interactive timeline showing Design -> Fabric Sourcing -> Pattern Making -> Sampling -> Production -> Quality Control -> Shipping.
- **Fabric Library**: Deep-dive into materials (GSM, compositions, organic certifications).
- **MOQ Calculator / RFQ**: High-converting lead generation tool.
- **FAQ**: Structured questions optimized for AEO/GEO.
- **Blog**: Industry insights, garment manufacturing guides, fabric guides.
- **Footer**: Organized link matrix, newsletter opt-in, organization schema triggers, social links.
